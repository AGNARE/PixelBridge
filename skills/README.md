# Скиллы для ИИ-агента

Эта папка — то, что превращает мост из «API, о котором надо знать» в
«инструмент, которым агент умеет пользоваться». Скиллы читает сам агент:
это не документация для человека, а рабочие инструкции для модели.

| Скилл | Роль | Что даёт |
|---|---|---|
| [`ux-ui-design/`](ux-ui-design/SKILL.md) | **дизайнер** | как думать и принимать решения: бриф, исследование, ИА, каркас, токены, состояния, доступность, передача. Чек-листы, формат обоснования, UX-аудит |
| [`figma-bridge/`](figma-bridge/SKILL.md) | **инструмент** | как рисовать в вашей Figma: цикл «построил → посмотрел → исправил», движок раскладки, правила геометрии, известные ограничения |

Два скилла работают в паре: `ux-ui-design` решает **что** рисовать,
`figma-bridge` — **как** это положить на холст без потери редактируемости.

## Установка

```
install-skills.cmd
```

Скрипт копирует обе папки в места, откуда DSH-агент их подхватывает:

- `%USERPROFILE%\.dsh\skills\`
- `%USERPROFILE%\.agents\skills\`

Вручную — просто скопируйте папки `figma-bridge` и `ux-ui-design` целиком в
любой из этих каталогов. Агент увидит новый скилл сразу, перезапуск не нужен.
Если папка `skills` из репозитория положена в проект, работают ещё два корня:
`<проект>/.dsh/skills` и `<проект>/.agents/skills`.

Формат скилла — каталог с файлом `SKILL.md`, в начале которого YAML-заголовок:

```markdown
---
name: figma-bridge
description: Когда применять этот скилл — по этому тексту агент решает,
  доставать его или нет.
---
```

Дополнительные `.md` и `.py` рядом со `SKILL.md` скилл подгружает сам, когда
они нужны.

## Что внутри `figma-bridge`

- **`SKILL.md`** — маршруты моста, формат спецификации `/api/build`,
  пять правил, которые чаще всего ломают сборку.
- **`ПРАКТИКА.md`** — каждая ошибка с ценой: геометрия, цвет, кадры, отладка,
  как получить 100 % авто-лейаут, замеры времени. **Дополняйте его после каждой
  сессии** — скилл без поддержки начинает врать через месяц.
- **`layout-engine.py`** — готовый движок раскладки. Считает размеры из
  содержимого и выдаёт координаты относительно родителя, поэтому сборка
  получается на 100 % редактируемым авто-лейаутом. Импортируйте его, а не
  считайте боксы руками:

  ```python
  from layout_engine import COL, ROW, T, build

  card = COL("card", pad=20, gap=12,
             style={"background": "#FFFFFF", "radius": 12},
             children=[T("t", 300, "Заголовок", 16, 700)])
  build("01 — Экран", ROW("root", w=1440, h=1024, children=[card]), bg="#F4F6F8")
  ```

  `build()` по умолчанию делает скриншот результата и возвращает путь к PNG —
  правило «посмотри на результат глазами» встроено в инструмент, а не оставлено
  на совесть.

## Обновление скилла из репозитория

Если поработали и узнали новое — допишите это в `ПРАКТИКА.md` **здесь**, в
репозитории, и запустите `install-skills.cmd` заново. Копии в
`%USERPROFILE%\.dsh\skills` — это выгрузка, источник правды лежит в git.
